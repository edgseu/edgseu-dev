# Context

## Glossary

### Site

The public experience at `edgseu.dev`, identified primarily as `edgseu`. “Aman Bhushan Singh” appears as the person introduced on the homepage rather than as the site-wide brand.

### GitHub Profile

The public `h1zardian` account that owns the repositories presented by the Site and supplies optional public metadata and the small profile avatar. It is distinct from the `edgseu` Site identity.

### Homepage

The recruiter-first profile surface that introduces the person behind `edgseu` and routes visitors to Projects and Articles. Its structure may reference GitHub profile conventions without reproducing GitHub’s identity.

### Interactive Terminal

The Homepage’s bounded signature introduction: static identity content enhanced with a small curated command interface. It is neither the Site’s primary navigation nor a general-purpose shell; every destination and identity fact remains available without interacting with it.

### Project

A publicly presented body of work represented in the first release by a Project Card that links to its GitHub repository. A Project is not a first-release on-site case-study page.

### Project Card

A curated summary of a Project. Selection, ordering, and display copy belong to the site owner; public GitHub facts may enrich the summary without becoming its source of editorial truth.

### Article

A locally authored long-form publication rendered as its own reading page with generated section navigation and a Giscus discussion block.

### First Release

The initial public Site consisting of the Homepage, Projects index, Articles index, and Article pages. It excludes on-site Project detail pages and broader publication or application features.
